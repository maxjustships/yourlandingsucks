# Changelog

All notable changes are documented here. This project uses semantic versioning,
including prerelease identifiers while the CLI and artifact schemas stabilize.

## 0.1.0-alpha.1 - 2026-07-17

- add strict feedback bundles, provider-neutral submission plans, and receipts;
- add daily maintainer planning, registration, heartbeat, ingest, triage, and
  resolution primitives;
- add a guarded maintainer Agent Skill with prompt-injection and human gates;
- clarify exact npm-registry installation and replace synthetic-test framing
  with the user pain and closed-loop outcome.

## 0.1.0-alpha.0 - 2026-07-17

Initial public alpha:

- prompt-native project Agent Skill with one-paste onboarding;
- human-confirmed multi-site scope, rules, schedules, and autonomy;
- deterministic browser, accessibility, performance, and journey evidence;
- contextual agent recommendations and preview verification;
- local issues and privacy-preserving feedback loop;
- external scheduler plans with registration and heartbeat health;
- packaged install, edge fixtures, and Windows/Linux/macOS CI coverage.
