# Support policy

YourLandingSucks is prerelease software.

- Only the latest published alpha receives fixes and security updates.
- CLI JSON, configuration, and artifact schemas remain versioned, but may change
  between prereleases before `1.0.0`.
- Bug reports must use a public fixture or minimal repository and must not attach
  raw `.yls/` data, credentials, private URLs, or analytics exports.
- Security reports belong in
  [GitHub private vulnerability reporting](https://github.com/maxjustships/yourlandingsucks/security/advisories/new),
  never in a public issue.

The public issue tracker is the support channel for safe, reproducible bugs and
focused feature requests. There is no response-time SLA for the open-source
alpha.
